# Relation Body Geometry: A Geometric Deconstruction of Transformers

[![TMLR Under Review](https://img.shields.io/badge/TMLR-Under%20Review-blue)](https://openreview.net/)
[![Framework](https://img.shields.io/badge/Framework-PyTorch-orange)](https://pytorch.org/)

This repository contains the official code, datasets, and supplementary materials for the two-part series on **Relation Body Geometry (RBG)**. We provide a unified geometric physics framework to deconstruct the internal mechanisms of Transformers, bridging Attention, Multi-Head, and Semantic Emergence.

## 📚 Series Overview

### 📄 [Paper I: Foundational Theorems](./Paper_I_Foundations)
*   **Title:** *Relation Body Geometry: A Geometric Theory of Attention*
*   **Status:** Under review at TMLR (Anonymous version available).
*   **Focus:** Establishes the foundational Relation Body Unit Circle ($c^2+s^2=1$), the negative correlation between attention probability and redundancy, and the global Tree/Bush structures.

### 📄 [Paper II: TSDP Framework](./Paper_II_TSDP_Framework) (Core)
*   **Title:** *Tri-Space Dual-Projection (TSDP) Framework*
*   **Status:** Draft complete. Full Chinese paper and English core chapters available.
*   **Focus:** Resolves the micro-mechanisms of Attention and Multi-head. Introduces the TSDP framework, Static/Dynamic Tree concepts, and provides rigorous causal interventions (e.g., QK routing collapse, MoE expert slicing).


