# Data Documentation (data/README.md)

This directory contains the raw and processed data for the paper *From Pythagoras to Transformers: A Geometric Theory of Attention via the Relation Body*. All data are generated by the scripts in `code/` and have not been manually modified.

## Directory Structure

```
data/
├── raw/                          # Raw experimental outputs
│   ├── batch_scan_results.csv
│   ├── local_pca_results.csv
│   ├── cross_model_results.csv
│   ├── layer11_head_ablation.csv
│   ├── layer11_head_features.csv
│   ├── layer_compare_features.csv
│   ├── ablation_layer.csv
│   ├── ablation_single.csv
│   ├── ablation_patch.csv
│   ├── cumulative_ablation.csv
│   ├── domain_width_results.csv
│   └── multi_seed_results.csv
└── README.md
```

## Raw Data (raw/)

### 1. batch_scan_results.csv

| Field | Type | Description |
|---|---|---|
| layer | int | Layer index (0–11) |
| head | int | Head index (0–11) |
| rA | float | Scheme A correlation coefficient |
| rB | float | Scheme B correlation coefficient |
| rC | float | Scheme C correlation coefficient |

- **Source**: GPT-2 small full layer-head scan
- **Generated by**: `code/analysis/batch_scan.py`
- **Size**: 144 rows (12 layers × 12 heads)

### 2. local_pca_results.csv

| Field | Type | Description |
|---|---|---|
| layer | int | Layer index |
| head | int | Head index |
| mean_conc | float | Mean local PC1 concentration |
| r_conc_entropy | float | Correlation between concentration and entropy |

- **Source**: GPT-2 small local PCA
- **Generated by**: `code/analysis/local_pca_analysis.py`
- **Size**: 144 rows

### 3. cross_model_results.csv

| Field | Type | Description |
|---|---|---|
| model | str | Model name ("gpt2" / "gpt2-medium") |
| layer | int | Layer index |
| head | int | Head index |
| rA | float | Scheme A correlation coefficient |
| mean_conc | float | Local PC1 concentration |
| r_conc_entropy | float | Correlation between concentration and entropy |
| head_dim | int | Head dimension (64) |

- **Source**: GPT-2 small + medium cross-model experiments
- **Generated by**: `code/analysis/cross_model_analysis.py`
- **Size**: 528 rows (144 + 384)

### 4. layer11_head_ablation.csv

| Field | Type | Description |
|---|---|---|
| head | int | Head index (0–11) |
| semantic | float | Semantic score after ablation |
| semantic_delta | float | Change in semantic score |

- **Source**: Layer 11 per-head ablation
- **Generated by**: `code/analysis/layer11_analysis.py`
- **Size**: 12 rows

### 5. layer11_head_features.csv

| Field | Type | Description |
|---|---|---|
| head | int | Head index |
| mean_entropy | float | Mean attention entropy |
| mean_conc | float | Mean PC1 concentration |

- **Source**: Layer 11 geometric features
- **Generated by**: `code/analysis/layer11_analysis.py`
- **Size**: 12 rows

### 6. layer_compare_features.csv

| Field | Type | Description |
|---|---|---|
| layer | int | Layer index (0 or 11) |
| head | int | Head index |
| mean_entropy | float | Mean entropy |
| mean_conc | float | Mean PC1 |

- **Source**: Layer 0 vs Layer 11 comparison
- **Generated by**: `code/analysis/layer11_analysis.py`
- **Size**: 24 rows

### 7. ablation_layer.csv

| Field | Type | Description |
|---|---|---|
| layer | int | Ablated layer index |
| syntax | float | Syntactic score after ablation |
| semantic | float | Semantic score after ablation |
| syntax_delta | float | Change in syntactic score |
| semantic_delta | float | Change in semantic score |

- **Source**: Layer ablation experiments
- **Generated by**: `code/analysis/ablation_v2.py`
- **Size**: 12 rows

### 8. ablation_single.csv

| Field | Type | Description |
|---|---|---|
| layer | int | Layer index |
| head | int | Head index |
| syntax | float | Syntactic score after ablation |
| semantic | float | Semantic score after ablation |
| syntax_delta | float | Change in syntactic score |
| semantic_delta | float | Change in semantic score |

- **Source**: Single-head ablation experiments (4 representative heads)
- **Generated by**: `code/analysis/ablation_v2.py`
- **Size**: 4 rows

### 9. ablation_patch.csv

| Field | Type | Description |
|---|---|---|
| layer | int | Layer index |
| head | int | Head index |
| syntax | float | Syntactic score after patching |
| semantic | float | Semantic score after patching |
| syntax_delta | float | Change in syntactic score |
| semantic_delta | float | Change in semantic score |

- **Source**: Activation patching experiments (4 representative heads)
- **Generated by**: `code/analysis/ablation_v2.py`
- **Size**: 4 rows

### 10. cumulative_ablation.csv

| Field | Type | Description |
|---|---|---|
| k | int | Number of ablated layers |
| ablated_layers | str | List of ablated layers |
| syntax | float | Syntactic score |
| semantic | float | Semantic score |
| syntax_delta | float | Change in syntactic score |
| semantic_delta | float | Change in semantic score |

- **Source**: Cumulative ablation experiments
- **Generated by**: `code/analysis/cumulative_ablation.py`
- **Size**: 11 rows (k = 0–10)

### 11. domain_width_results.csv

| Field | Type | Description |
|---|---|---|
| domain | str | Domain (repeat/single/double/multi) |
| layer | int | Layer index |
| head | int | Head index |
| rA | float | Scheme A correlation coefficient |
| mean_conc | float | Local PC1 concentration |

- **Source**: Controlled-domain experiments
- **Generated by**: `code/analysis/domain_width_experiment.py`
- **Size**: 576 rows (4 domains × 12 layers × 12 heads)

### 12. multi_seed_results.csv

| Field | Type | Description |
|---|---|---|
| text | str | Input text type (news/code/poetry/dialogue/math) |
| layer | int | Layer index |
| head | int | Head index |
| mean_conc | float | Local PC1 concentration |

- **Source**: Multi-seed / multi-input robustness check
- **Generated by**: `code/utils/plot_figA4.py`
- **Size**: 720 rows (5 texts × 12 layers × 12 heads)
